\section{Team Collaboration and Version Control}

\subsection{Git Workflow and Policy}
Work is organized through branch isolation and commit-level history. Deliverable~2 was
developed on dedicated feature branches and integrated on \texttt{deliverable-2};
Deliverable~3 is integrated on \texttt{deliverable-3}, which contains the Phase~5
analysis, the final report, and the reproducibility artefacts:
\begin{itemize}
    \item \texttt{d2/zia-eval} $\rightarrow$ \texttt{deliverable-3} (Lead: Abdullah Zia): Search algorithms, metrics framework, evaluation harnesses, fallback neural models, paired failure analysis, feature ablation, demo, and report synthesis.
    \item \texttt{d2/saeed-training} (Lead: Muhammad Abdullah Saeed): Data manifest generation, PyTorch datasets and data loaders, multi-stage hyperparameter tuning, model training, and artefact policy.
    \item \texttt{d2/hamid-model} (Lead: Muhammad Hamid Abad): Neural architecture implementation, feature pipeline refactoring, search heuristic wrappers, ablation design, and architectural visualizations.
\end{itemize}
